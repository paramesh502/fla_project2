DFA (7 states, subset construction)

ε-closure({q0}) = {q0,q2}, so the DFA start state is {q0,q2}. Each DFA state is a subset of NFA states.

Minimized DFA (Myhill-Nerode / table-filling)

States with identical future behaviour are merged. D2={q3} and D5={q7} are indistinguishable → merged.

What the States Mean

Start state {q0,q2}: firewall entry. ε-closure includes q2 (the proxy tunnel).

Accept state {q4}: server reached — BREACH SUCCESSFUL.

TRAP: intrusion alarm triggered. Absorbing — no recovery.
